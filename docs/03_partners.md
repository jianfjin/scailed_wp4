# EPIDATA — Overall Role

EPIDATA is:

* co-lead of **WP4 — Pathfinder System (Monitor and Evaluate Progress)**,
* responsible for developing the operational “Pathfinder” monitoring and navigation framework,
* central to evaluation, monitoring, stakeholder guidance, and operationalization of the Strategic Roadmap. 

---

# 1. Project Phases Involving EPIDATA

The proposal defines an iterative project lifecycle:

1. **Analyse**
2. **Implement**
3. **Test**
4. **Scale**

EPIDATA participates in all four phases. 

| Phase     | EPIDATA Role                                            |
| --------- | ------------------------------------------------------- |
| Analyse   | Build monitoring framework using WP2/WP3 inputs         |
| Implement | Develop Pathfinder system and evaluation tools          |
| Test      | Validate Pathfinder using pilots/use cases/AI Factories |
| Scale     | Finalize and publish reusable guidelines/framework      |
