# Pathfinder 跨 WP 交界语言

适用于 WP2/WP3/WP4/WP8 之间的内容交换与责任讨论。这里的词语与采购文档中的专用称谓分别维护。

## Language

**源内容（Source Content）**：
由负责 WP 提供并承载其业务含义的分类词汇、路线图、法规规则及引用等领域内容。
_Avoid_：未区分含义与载体的「上游数据」

**内容负责方（Content Owner）**：
对某项源内容的业务含义承担解释与变更确认职责的工作包。
_Avoid_：未注明内容、格式或运行职责的「owner」

**Pathfinder 交界约定（Boundary Contract）**：
生产方和消费方对跨 WP 交换内容、业务含义及兼容性形成的共同约定。
_Avoid_：仅指交换格式的「字段表」

**保义适配（Meaning-preserving Adaptation）**：
将源内容转换为 Pathfinder 可使用的表达，同时保留原有业务含义的转换。
_Avoid_：未区分表示转换与含义变化的「数据清洗」

**普通内容交付（Routine Content Delivery）**：
在既定业务含义和兼容约定内，由内容负责方发布的一批内容版本。
_Avoid_：仅因字段结构未变就判定的「普通更新」

**内容确认（Content Confirmation）**：
内容负责方对本批交付内容所作的业务确认。
_Avoid_：消费方的接入验收、仅通过格式检查

**接入验收（Delivery Acceptance）**：
消费方依据既定交界约定，对本批交付是否满足接入要求的确认。
_Avoid_：代替内容负责方解释业务含义、无条件自动激活

**交界变更（Boundary Contract Change）**：
改变跨 WP 交换内容的约定含义或兼容关系的变更，即使其载体结构保持不变。
_Avoid_：仅按字段增删识别的「格式变更」

**内容撤回（Content Withdrawal）**：
内容负责方明确声明某个已发布版本不再作为当前推演依据的业务决定。
_Avoid_：普通版本替换、仅有弃用标记、新版本验收失败

**精确版本依赖（Exact Version Dependency）**：
一份交付内容需要配合另一份指定版本的内容解释和使用的关系。
_Avoid_：版本替换沿革、同一工作包提供内容就视作相互依赖

**受影响输入组合（Affected Input Set）**：
直接包含被撤回版本，或所用内容直接或间接依赖该版本的输入组合。
_Avoid_：同一工作包的所有版本、整个 Pathfinder 的全部输入

## 机构、类型与角色

**机构（Organization）**：
在业务场景中参与数据活动的具体组织主体。机构身份与其参与者分类、在具体场景中承担的角色分别表达。
_Avoid_：用「参与者类型」指代某家具体机构

**参与者类型（Stakeholder Type）**：
WP2 分类体系中的类别，例如「生物技术 SME」。类别本身不代表某家具体机构的身份或该机构在某个场景中的实际角色。
_Avoid_：机构 ID、类型与角色拼接而成的混合分类

**场景角色（Scenario Role）**：
某一机构在特定业务场景中承担的职能或参与身份，例如提供数据或使用数据。同一机构在不同场景中可以承担不同角色。
_Avoid_：机构的永久属性、由参与者类型直接推定的实际角色

## 评估

**独立评估会话（Independent Assessment Session）**：
针对所选参与者类型与目标场景的一次评估，包含该次回答、评估状态与结果。不同会话之间不建立同一机构的归属或历史关系。
_Avoid_：机构档案、机构的跨期评估历史

**历史评估（Historical Assessment）**：
按当时输入版本和回答形成并保留的评估记录。记录可追溯不代表其结果在当前仍是有效建议。
_Avoid_：当前有效建议、可持续使用的旧结论

## 能力

**能力词汇（Capability Vocabulary）**：
WP2 分类体系中用于共同指代各项能力的词汇集合。
_Avoid_：具备能力的机构名单、本次能力清单

**类型参考能力（Type Reference Capability）**：
WP2 分类中与某种参与者类型关联的能力信息，描述类型层面的参考特征。它不构成某次评估具备该能力的认定。
_Avoid_：本次默认具备的能力、已核实能力

**本次能力判断（Assessment Capability Finding）**：
针对当前评估会话，依据该次回答与相应证据形成的能力判断或待确认状态。
_Avoid_：类型参考画像、从参与者类型自动继承的能力

**未知能力状态（Unknown Capability Status）**：
当前评估信息不足以判断是否具备某项能力的状态。未回答且无其他依据，不构成具备或不具备的事实。
_Avoid_：明确不具备、默认具备

**明确否定的能力判断（Explicit Negative Capability Finding）**：
当前回答或相应证据对本次是否具备某项能力作出的明确否定判断。
_Avoid_：未回答、未知

**自报能力（Self-reported Capability）**：
本次回答者声明具备的能力，其来源为本次评估的自报回答。自报可以作为注明依据的推演输入，但不代表该声明已经完成核验。
_Avoid_：已核验能力、经独立确认的能力

**能力核验状态（Capability Verification Status）**：
对某项本次能力判断是否完成所约定核验的说明，与能力判断的肯定、否定或未知分别表达。自报具备可以同时处于未核验状态。
_Avoid_：填写完整度、用单一置信度数字代替核验说明

## 路径建议

**条件性方向（Conditional Guidance）**：
在相关必要条件尚未确认时提供的候选方向，附带其成立所需确认的信息。它不构成该路径已满足条件或可执行的结论。
_Avoid_：已确认可执行路径、已满足全部条件的推荐

**待补信息（Information Needed）**：
为判断某项必要条件是否成立而仍需补充的回答或相应依据。
_Avoid_：已确认不具备的能力、已经成立的阻塞事实
