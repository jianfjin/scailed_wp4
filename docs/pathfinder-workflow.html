01Condition DSL — Rule Evaluation

Condition Types

atomic{ field, operator, value } — eq/ne/gt/gte/lt/lte/in/not_in/contains/exists
AND{ and: [cond, ...] } — all must match
OR{ or: [cond, ...] } — any matches
NOT{ not: cond } — negates sub-condition
empty{ } — always match

Rule Types

eligibilityPrerequisite check — must pass
exclusionBlocks path entirely
preferenceRecommends action (non-blocking)
overrideForces reroute to specific node
action{ title, text, node_id?, warning?, block? }
