# V1 以独立评估会话承载评估

建立稳定机构身份可以关联同一机构的多次评估，但同时引入机构身份来源、维护和关联责任；用户在领域建模讨论第 5 问选择独立评估会话。决定：V1 记录本次评估的参与者类型与场景，不建立机构档案，也不把不同会话组织成同一家机构的历史。机构、参与者类型和场景角色在业务概念上仍然分别表达，后续增加机构身份与跨会话关联需要单独决定范围和责任。

## 后果

相同参与者类型、场景或相似答案不能作为历史会话属于同一家机构的依据；未来如需机构关联，不能把既有独立会话默认解释为机构纵向历史。这里确定的是业务身份与关联范围，不是对日志、审计或系统匿名性的声明。
