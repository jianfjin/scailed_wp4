3. Domain Models

Frozen dataclasses in pathfinder/core/models.py — immutable, thread-safe.

RoadmapNode

@dataclass(frozen=True)
class RoadmapNode:
    node_id: str              # "generic-intake"
    label: str                # "Confirm stakeholder baseline"
    description: str
    dimension: str            # "governance" | "data" | "compliance"
    maturity_level: int       # 1-5
    stakeholder_types: tuple[str, ...]  # ("all",) | ("biotech-sme", ...)
    prerequisites: tuple[str, ...] = ()
    source_wp: str = "WP3"
    source_doc_ref: str = "demo-data"
    confidence: float = 1.0
    metadata: dict = {}

    def applies_to(self, stakeholder_type: str) -> bool:
        return stakeholder_type in self.stakeholder_types or "all" in self.stakeholder_types

RoadmapEdge

@dataclass(frozen=True)
class RoadmapEdge:
    edge_id: str              # "e1"
    from_node_id: str         # "generic-intake"
    to_node_id: str           # "governance-scope"
    relation_type: str = "prerequisite"
    required: bool = True
    source_doc_ref: str = "demo-data"

frozen=True means immutable after creation. Thread-safe, hashable, no accidental mutation.

The key routing logic: applies_to(stakeholder_type) — a node with ("all",) applies to everyone. A node with ("biotech-sme", "research-infrastructure") only applies to those two.

4. Graph Construction: Two Backends, One Interface

InMemoryRoadmapGraph

Demo mode — graph.py

class InMemoryRoadmapGraph:
    def __init__(self, nodes, edges):
        self.nodes = {n.node_id: n for n in nodes}
        self.edges = edges
        self._outgoing = {}
        for edge in edges:
            self._outgoing.setdefault(
                edge.from_node_id, []
            ).append(edge.to_node_id)

One hash map + one adjacency list. Instant.

AgeRoadmapGraph

Deployed mode — graph_age.py

class AgeRoadmapGraph:
    def __init__(self, dsn=None):
        self._dsn = dsn
        self._pool = None       # lazy
        self.nodes = {}          # empty!
        self.edges = []          # empty!
        self._connected = False

Constructor stores DSN only. Data loaded later in connect() + load_demo_data().

The Dual Write — Why Both?

# graph_age.py — load_demo_data()
async def load_demo_data(self, nodes, edges):
    # ═══ WRITE 1: In-memory ═══
    self.load_projection(nodes, edges)
    #   self.nodes["generic-intake"] = RoadmapNode(...)
    #   self.edges = [RoadmapEdge("e1", ...), ...]

    # ═══ WRITE 2: AGE graph (advisory locked) ═══
    async with self._pool.acquire() as conn:
        await conn.execute("SELECT pg_advisory_lock(73109741);")
        for node in nodes:
            await conn.execute(_LOAD_NODE % (...))
        for edge in edges:
            await conn.execute(_LOAD_EDGE % (...))
        await conn.execute("SELECT pg_advisory_unlock(73109741);")
Write targetUsed byPurpose
memory self.nodes / self.edges shortest_path(), locate_current(), applicable_nodes() Fast Python BFS — no DB call
AGE pathfinder_graph Nothing yet (cypher_query() available for V2) Reserve — V2 graph analytics

5. Full End-to-End Flow (Deployed Mode)

Phase 1 — Data Source
wp3_data.json (on disk, WP3 mock container)
↓ aiohttp.web server, port 8080
GET /api/v1/roadmap/nodes → JSON list of node dicts
GET /api/v1/roadmap/edges → JSON list of edge dicts
↓
UpstreamClient.fetch_roadmap()
- HTTP GET with retry (3 attempts, exponential backoff)
- JSON dict → RoadmapNode / RoadmapEdge domain models
- Cached in self.roadmap_nodes / self.roadmap_edges

Phase 2 — Service Init (FastAPI Lifespan)
upstream_client.startup()
→ fetch_stakeholders() (WP2)
→ fetch_roadmap() (WP3) ← graph data
→ fetch_rules() (WP8)
↓
AssessmentService(upstream_client=client)
→ _load_upstream_data(client)
self._active_roadmap = (nodes, edges)
↓
if deployed: await service.connect_age()
→ graph.connect() (asyncpg pool, min=1, max=4)
→ graph.load_demo_data(nodes, edges)
├── memory load_projection()
└── AGE MERGE into pathfinder_graph

Phase 3 — Query
POST /v1/assessments/{id}/recommendations
→ solver.solve(state, rules)
→ graph.locate_current(state) ← self.nodes
→ graph.locate_target(state) ← self.nodes
→ graph.shortest_path(from, to) ← self.edges → BFS
→ rule matching ← self.rules
→ build_recommendation(path)
→ return PathResult

7. Hot Reload

POST /admin/import/wp3 (requires admin-token) allows reloading roadmap data at runtime:

AssessmentService.import_wp3(json_payload)
  │
  ├── _roadmap_from_wp3(payload)    ← parse + validate
  │     for each node dict: validate fields, check duplicates, RoadmapNode(...)
  │     for each edge dict: validate refs exist, check duplicates, RoadmapEdge(...)
  │
  ├── self._active_roadmap = (nodes, edges)
  │
  ├── if AGE backend:
  │     graph.load_projection(nodes, edges)  ← update memory only
  │   else:
  │     self.graph = InMemoryRoadmapGraph(nodes, edges)
  │
  ├── self.solver = PathfinderSolver(self.graph)
  └── self.audit_log.append("data_imported", {...})

Hot reload updates the in-memory projection immediately. AGE sync on hot reload is not implemented — currently only touches the memory projection.
