# D4.1 Pathfinder Demo Script

## Setup
1. Start backend and frontend from Docker Compose or local dev commands.
2. Use demo token `demo-token`.
3. Select stakeholder type `biotech-sme`.
4. Select target scenario `secondary-use-readiness`.

## Flow
1. Open Pathfinder.
2. Confirm mock-data banner is visible.
3. Run the assessment with demo answers.
4. Confirm recommendation status, roadmap steps, warnings, triggered rules, and trace payload.
5. Export/view report.
6. Confirm audit chain is valid.

## Acceptance Evidence
- At least five stakeholder types are available.
- Recommendation includes roadmap node IDs and rule IDs.
- Report includes demo disclaimer and missing-data warning.
- Audit chain reports valid.
